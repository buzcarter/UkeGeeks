UkeGeeks Scriptasaurus

Turn ChordPro-marked lyrics into printable ukulele song sheets, with chord diagrams drawn for you.

See it in action

The Songbook Song list, quick search and the Song-a-matic editor: transpose, retune, restyle One song Chord diagrams and lyrics from a single <pre> block Several songs on a page Each song gets its own diagrams

Use it on your own page

Write your song in ChordPro markup (chords in brackets, like [C]Some [G7]lyrics), drop it into this markup, and run the script:

<link rel="stylesheet" href="css/ukeGeeks.music.css" />

<div id="ukeSongContainer">
  <aside id="ukeChordsCanvas"></aside>
  <article id="ukeSongText">
    <pre>{title: My Song}
[C]Some [G7]lyrics</pre>
  </article>
</div>

<script src="js/ukeGeeks.scriptasaurus.min.js"></script>
<script>
  ukeGeeks.scriptasaurus.init(false);
  ukeGeeks.scriptasaurus.run();
</script>

Run the full songbook

The songbook (song list, quick search, the Song-a-matic editor, transposing and saving) runs on a small Node.js server, or on PHP:

git clone https://github.com/buzcarter/UkeGeeks.git
cd UkeGeeks
npm start
